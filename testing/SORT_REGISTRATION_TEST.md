## C. Excel экспорт (аль ч оператороор)

- [ ] **C1.** Жагсаалтаас "Excel татах" → файл татагдана
- [ ] **C2.** Багана толгойнууд: Рам цаг, Ц.дугаар, Цутгасан ээлж, ... , Сорт цаг, Төлөв —
      «Зүсэлтийн хэмжээ», «Ээлж №», «Сортлогч» толгой 2-р мөрд **хаана ч байхгүй**
- [ ] **C3.** ①-р бичлэгийн мөр: тоонууд (350/6/2/2), м³ утгууд, төлөв "дууссан"
- [ ] **C4.** Цагууд Улаанбаатарын цагаар зөв харагдана
- [ ] **C5.** **Хугацааны интервал (олон өдөр)** — "Эхлэх огноо" = бүртгэлтэй эрт өдөр,
      "Дуусах огноо" = бүртгэлтэй хожуу өдөр, Ээлж = "Бүтэн өдөр" → "Excel татах" →
      татагдсан файлд интервалын **өдөр бүрийн** бүртгэл байна (эхлэх ба дуусах өдрийг
      хоёуланг нь ОРУУЛААД); мөрийн тоо дэлгэц дээрх "Нийт:"-тэй тэнцүү
      (DevTools → Network: хүсэлтэд `dateFrom=…&dateTo=…`, `date` БАЙХГҮЙ)
- [ ] **C6.** **Нэг өдрийн интервал** — "Эхлэх огноо" = "Дуусах огноо" = C1-д туршсан өдөр →
      хүсэлтэд зөвхөн `date=…` (`dateFrom`/`dateTo` байхгүй), татагдсан файл нь хуучин
      нэг "Огноо"-гоор шүүсэнтэй **яг ижил** мөрүүдтэй
- [ ] **C7.** **"Одоогийн ээлж"** товч — дурын шүүлтүүр өөрчилсний дараа дарах → Эхлэх ба
      Дуусах огноо хоёул одоогийн ээлжийн огноо болж, Ээлж нь явж буй ээлж (Өдөр/Шөнө)
      болж сэргэнэ; хүсэлт `date=…&shift=…` (интервалын параметргүй); тухайн ээлжийн
      Excel хэвийн татагдана
- [ ] **C8.** **"200/100 задаргаа"** маягтыг мөн олон өдрийн интервалаар татах →
      `GET /api/sort/records/export-dual?…dateFrom=…&dateTo=…` амжилттай, файлын
      "НИЙТ" мөр интервалын тоонуудтай тохирно
- [ ] **C9.** "Уламжлалт маягт"-аар татсан файлыг Excel-д нээх → **2-р мөрийн багана
      бүрд шүүлтүүрийн сум (▼)** харагдана; доош гүйлгэхэд 1-2-р мөр, баруун тийш
      гүйлгэхэд "д/д" багана **хөлдсөн** байна; ж: "Төлөв" → "дууссан" шүүхэд зөвхөн
      дууссан мөрүүд үлдэнэ; нээхэд Excel **"нөхөн сэргээх" сануулга гаргахгүй**
- [ ] **C10.** "200/100 задаргаа" файлыг нээх → шүүлтүүр 2-р мөрд байна, муж нь
      **НИЙТ мөрөөс ДЭЭШ** дуусна — дурын шүүлтүүр тавихад доод талын **"НИЙТ" ба
      "үүнээс …" 3 мөр хэвээр харагдана**. Хос горимын таних утга, шалтгаанууд
      хоёр мөрт давтагдана; эдгээр баганаар шүүхэд 200мм/100мм мөр хоёул үлдэнэ.
- [ ] **C11.** **Хассан баганууд** — "Уламжлалт маягт": 2-р мөрд «Зүсэлтийн хэмжээ» (3 байсан),
      «Ээлж №», «Сортлогч» **байхгүй**; багана 28, сүүлчийнх **AB**, шүүлтүүрийн муж `A2:AB<n>`.
      "200/100 задаргаа": «Сортлогч» **байхгүй**; багана 19, сүүлчийнх **S**, шүүлтүүр `A2:S<n>`,
      хөлдөөсөн зүүн хэсэг «Хэмжээ» багана (H) хүртэл.
- [ ] **C12.** **Том экспорт** — 7,500 орчим бүртгэлээр "200/100 задаргаа" татах
      зуур `GET /api/health/db` давтан дуудах → экспорт хэдхэн секундэд дуусна,
      health хүсэлтүүд экспортыг дуустал хүлээхгүй. 50,000-аас их бүртгэлтэй
      хүрээнд 413 болон огнооны шүүлтүүрээ багасгах тайлбар буцна.

## F. Рам + Сорт хосолсон эрх (`sortDualRole=true` акаунт)

Зорилго: рам болон сортын үүргийг **нэг** акаунт дээр хослуулах шинэ тохиргоог шалгах —
`role='operator'`, `stationCode` нь `ҮЯ-160`/`СОРТ` **биш** (жишээ: `null` эсвэл `ҮЯ-110`)
байхад ч, `sortDualRole=true` бол тухайн хэрэглэгч рам болон сортын алхам хоёуланг нь
дангаараа хийж чадах ёстой.

Бэлтгэл: Админ → Хэрэглэгчид → dual.test-ийг "Хэрэглэгч засах" → "Рам + Сорт хосолсон эрх"
свичийг **асаах** → Хадгалах.

- [ ] **F1.** Хадгалахад алдаагүй, аудит лог руу `user_sort_dual_role_changed` бичигдэнэ
      (эсвэл ерөнхий `user_updated` тэмдэглэлд `sortDualRole: true` харагдана)
- [ ] **F2.** dual.test-ээр нэвтрэх → Sidebar-д "Сорт бүртгэл" цэс харагдана
- [ ] **F3.** `/sort-registration` нээгдэж, "Шинэ бүртгэл" товч харагдана (РАМ-ын станцгүй ч)
- [ ] **F4.** Шинэ бүртгэл үүсгэх (`POST /api/sort/records`) амжилттай → дэлгэрэнгүй хуудас руу орно
- [ ] **F5.** Тухайн бичлэгийн дэлгэрэнгүй хуудсанд **"1) Рамны мэдээлэл"** болон
      **"2) Сортын мэдээлэл"** хоёр форм **зэрэг** харагдана (D1-тэй адил admin-ий зан төлөв)
- [ ] **F6.** "1) Рамны мэдээлэл" формыг засаж хадгалах →
      `PATCH /api/sort/records/[id]` `ok: true`
- [ ] **F7.** Рам №/Хэмжээ хадгалах → `PATCH /api/sort/records/[id]/sort-header` `ok: true`
- [ ] **F8.** Сортын тоог зөв бөглөж "Дуусгах" → `PATCH /api/sort/records/[id]/sort` `ok: true`,
      badge "дууссан" болно — өөр акаунт руу шилжихгүйгээр ганцаараа бичлэгийг эхнээс
      дуустал бүрэн хийж дуусгасан байна
- [ ] **F9.** "Устгах" товч **харагдахгүй** (эсвэл шууд `DELETE /api/sort/records/[id]`
      дуудвал 403 буцна) — устгах эрх зөвхөн admin-д хэвээр
- [ ] **F10.** `sortDualRole=false` (эсвэл огт тохируулаагүй) энгийн ҮЯ-110 operator-оор
      нэвтрэх → A/B/E хэсгүүдийн адил хэвээр, "Сорт бүртгэл" харагдахгүй (регресс шалгалт)
- [ ] **F11.** dual.test-ээр `/sort-registration` дээр "Excel татах" товч дарж
      `GET /api/sort/records/export` **амжилттай** (403 биш) татагдана; мөн
      "200/100 задаргаа" `GET /api/sort/records/export-dual` **амжилттай** (403 биш) татагдана
