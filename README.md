# MAK-Euro-Block

Euroblock shift registration system built with Next.js, NextAuth, Prisma, and PostgreSQL.

## Run Locally

**Requirement:** Node.js

1. `npm install`
2. Copy `.env.example` to `.env.local` and configure NextAuth plus PostgreSQL.
3. `npm run dev`

## Technology

Next.js, TypeScript, NextAuth, Prisma, PostgreSQL, and Vercel Blob.
