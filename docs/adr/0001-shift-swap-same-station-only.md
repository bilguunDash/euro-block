# Ээлж солилцоог зөвхөн ижил дамжлагад хязгаарлах

Оператор хоорондын ээлж солилцох (`ShiftSwapRequest`) нь зөвхөн ижил `stationCode`-той
`OperatorSchedule` мөрүүдийн хооронд боломжтой. Энэ бол v1-ийн энгийн байдлын төлөө биш,
бодит хязгаарлалт: оператор бүр зөвхөн өөрийн дамжлагад сургагдсан/эрхтэй тул өөр станцад
шилжиж ажиллах боломжгүй. Иймд станц хоорондын солилцоог алгасах бус, бүрмөсөн блоклоно.

**Status**: accepted

Ирээдүйд станц хоорондын солилцоог нээх санал гарвал, энэ бол зөвхөн код хасах асуудал биш —
эхлээд оператор бүрийн олон станцад ажиллах эрх/сургалтын мэдээллийг систем дотор бүртгэх
шаардлагатай болно.
