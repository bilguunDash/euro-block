# Ээлж солилцоо: мастер/админы баталгаажуулалтгүйгээр, оператор хоорондоо шийддэг

`ShiftSwapRequest` бол зөвхөн хоёр операторын хооронд шийдэгддэг — хүсэлт илгээгч санал болгож,
хүлээн авагч зөвшөөрөх/татгалзахаас өөр эрх бүхий этгээд (мастер, админ) оролцдоггүй. Энэ нь
ижил системийн дамжлага хүлээлцэх (`handoverStage`) процесстой ялгаатай — тэнд мастер/админы
баталгаажуулалт заавал шаардлагатай.

Шалтгаан: Солилцох хоёр тал хоёулаа аль хэдийн тухайн станцад ажиллах эрхтэй (ижил
`stationCode` — ADR 0001 харна уу), мөн зөвхөн ирээдүйн, ажил хараахан эхлээгүй
(`OperatorSchedule`) слотыг л хамарна (ADR 0004 харна уу). Тиймээс мастерын оролцоо
шаардлагатай "хариуцлага бодитоор шилжих" мөч биш — зөвхөн төлөвлөгөөний өөрчлөлт. Мастер үр
дүнг хуваарийн дэлгэцээр харах боломжтой хэвээр.

**Status**: accepted

Хэрэв ирээдүйд мастерт татгалзах эрх өгөх шаардлага гарвал, энэ нь зөвхөн UI нэмэлт биш —
notification/therefore-баталгаажуулалтын урсгал шинээр нэмэгдэх ёстой тул зардал багагүй.
