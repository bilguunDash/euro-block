# Ажил эхэлсэн слотыг солилцох боломжгүй — Swap ба Handover тусдаа механизм

`ShiftSwapRequest` нь зөвхөн `Shift` бичлэг хараахан үүсээгүй (өөрөөр хэлбэл ажил бодитоор
эхлээгүй) `OperatorSchedule` слот дээр л ажиллана. Тухайн слот дээр аль хэдийн `Shift` үүссэн
(цуцлагдаагүй) бол — хүсэлт үүсгэх үед ч, зөвшөөрөх үед ч — солилцоог блоклоно, мастер/админ
ч гэсэн энэ хориг дээгүүр гарах боломжгүй.

Шалтгаан: Ажил эхэлсний дараа хариуцлага шилжүүлэх цорын ганц зам бол `handoverStage`
дамждаг батлагдсан процесс (waiting_current_master → waiting_next_master →
waiting_next_operator → accepted/returned). Swap механизм нь энэ процесстой давхцаж, хоёр
өөр зөвшөөрлийн урсгал зэрэг ажиллах эрсдэлийг үүсгэхгүйн тулд бүрмөсөн тусад нь байлгав.

**Status**: accepted

Ирээдүйд явцад буй ээлжийг "swap" хийх хэрэгцээ гарвал, энэ бол шинэ swap логик нэмэх биш —
handoverStage процесстой хэрхэн уялдуулахаа шинээр шийдэх ёстой асуудал.
